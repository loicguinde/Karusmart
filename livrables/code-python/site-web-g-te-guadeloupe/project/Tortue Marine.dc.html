L’emplacement

Quartier de l’Autre Bord, entre la plage et le port

Les bungalows se trouvent à l’Autre Bord, sur la commune du Moule. La plage se rejoint à pied en deux minutes ; le port de pêche, où l’on achète le poisson du jour, est juste à côté. Le centre-ville et ses commerces sont à quelques minutes, de quoi vivre le séjour sans dépendre de la voiture.
